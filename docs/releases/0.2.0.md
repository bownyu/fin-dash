# FinDash 0.2.0 Release Notes

发布日期：2026-10-02 · Android 构建号：4

Agent 现在以用户任务组织确认流程。同一批账单默认汇总在一张方案卡片中，查看明细、处理例外后统一确认，不再逐张卡片点击。

## 交互变化

- 对话显示方案范围、操作分组、数量、待核对项与实际余额影响。账单重分类直接显示原分类与新分类。
- 明细页支持选择明确项、单项调整、排除及冲突重审；确认按钮固定在底部，支持窄屏和大字体。
- 暂定项和冲突项默认不选中。方案更新后旧审阅失效；后续文字修正可更新原方案。
- 生成中断可继续准备，也可明确选择只执行已准备部分。应用重启保留待处理方案。
- 确认和撤销以批次执行，统一校验并保存；失败全部回滚，只生成一份汇总回执。
- 新增账户及其账单可以一起审阅，系统处理执行顺序；不同任务和会话不混合确认。
- 历史多项提案自动归组；操作管理页保留辅助入口。

## 数据与工具

新增方案数据保存在现有扩展字段中，不升级 SQLite 或备份 schema。旧账本、迁移、备份、支付通知与语音记账继续使用既有存储接口。

新增 propose_changes 和 revise_changes，仅能准备／修改提案，不能执行写账。批量工具每次最多 200 项，待确认队列最多 2000 项；提案查询支持当前会话内分页。

完整设计：[Agent 任务级审阅与执行](../agent-batch-design.md)。
