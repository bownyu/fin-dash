# FinDash 0.5.8

日期：2026 年 10 月 4 日。Android 构建号：17。从 0.5.7 可直接覆盖升级。

## 主题切换

外观保存成功后，在首帧统一更新浅色 / 深色配色，取消全局 ThemeData 插值。这避免了每个动画帧重建依赖主题的页面（包括已访问的隐藏标签页）、重新计算摘要和列表，并反复重绘玻璃导航。玻璃材质与页面切换动画保留，标签页状态继续保留。

外观偏好改用现有元数据事务，共享已提交的财务列表，不再为一个外观选项创建完整账本改动。选择当前外观直接关闭面板。仍先完成持久化，再发布内存状态；保存失败保持原主题与选择面板。

## 数据兼容

沿用现有存储后端与事务，不修改账本结构、SQLite `user_version` 或备份 schema。浏览器端仍使用原有 JSON 存储，不具备原生 SQLite 的元数据增量写入能力。

## 验证

- 主题测试 9 项、版本一致性测试 1 项，以及现有 SQLite 大账本测试 1 项通过；没有运行全量回归。
- 访问全部 4 个主标签页后，主题在保存成功后的首帧更新，每个页面只重建一次；后续 16 帧（共 256 毫秒）不再重建这些页面，原页面状态保留。
- 核对外观保存、重开恢复、保存失败保持原主题，以及两种主题下的小屏 / 宽屏和较大字号布局。
- 2,000 多笔账单的 SQLite 账本切换主题只改写 1 行设置，扫描行数少于 100；财务列表保持原对象、财务版本不变，重新打开后的完整账本一致。
- 修改的 5 个 Dart 文件静态检查通过；package config 与插件路径继续使用项目内 `.pub-cache`，没有新增依赖。
- ARM64 release 构建成功，应用 ID 为 `com.findash.fin_dash`，版本为 `0.5.8+17`；APK 签名验证通过，签名证书与 0.5.7 一致，可覆盖升级。

性能验证针对 Flutter widget 重建与原生存储写入范围，尚未测量目标手机的实际帧率。
