# FinDash 0.4.0

日期：2026 年 10 月 3 日。Android 构建号：7。

本版将 AI Native 设计的业务内核、能力目录、任务与交互、查询程序接入现有应用。基础记账仍可在未配置 AI 时独立使用。

## 使用变化

- 手动、语音、通知、导入和 AI 交易准备采用共同校验；锁定后不能提交原审阅方案。编辑表单检测旧记录，失败保留输入。
- 聊天工具可以发现实际能力，查询带范围、整数分、快照及完整性。支持有预算的组合分析，不执行任意代码或 SQL。
- 聊天与操作管理可打开“任务与回执”，补全账户等信息、继续中断任务、查看方案与保存结果。语音草稿可恢复，忙时最多排队 3 条，并可单独停止。
- 长期记忆、偏好和目标先显示待审阅内容，确认后才保存，可条件撤销。模型猜测不能直接写入画像。
- 查询结果使用原生数据卡，可保存查询程序并在“常用分析”重新计算。
- 元数据写入与财务载荷分离，AI 状态、日志和聊天不再使账单页重建。原生 SQLite 支持受影响记录提交和索引分页查询。

## 数据兼容

备份 schema 为 2，仍读取 schema 1 和旧版 wallet 备份。新增分类 ID、来源与日期精度字段；无法证明的历史来源与时间精度保留 unknown。旧 JSON 源文件、损坏恢复副本和恢复前快照继续保留。SQLite 仍使用原来的单一记录表和跨文件事务，未切换 WAL。

## 验证与边界

静态检查无问题；Flutter 全量 248 项通过、1 项私人样本跳过，最终补充回归 22 项通过；Android 原生 22 项通过。ARM64 release 构建与签名验证通过，证书与 0.3.0 一致。详细验证结果和合成性能数据见 [实施记录](../ai-native/implementation-report-0.4.0.md)。真实模型网关、Android 真机帧率、权限和杀进程恢复需在相应环境实测；自动化不能替代真机结果。

原生查询已经使用 SQLite；旧页面的内存查询适配与启动全量账本加载仍保留，任意 IANA 时区、银行资金操作不支持。页面或模型只能调用当前注册的能力。
