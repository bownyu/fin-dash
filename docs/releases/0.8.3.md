# 0.8.3 — 2026-10-06

本次交付 AI 顾问输入法与滚动卡顿修复源码，版本 `0.8.3+19`，并生成 arm64 安装包 `build/app/outputs/flutter-apk/app-release.apk`（344.7MB），未发布。

## 原因

- 弹出输入法时，每一帧都会改变键盘高度。首页外壳的 `Scaffold` 随键盘缩小内容区，`IndexedStack` 会布局全部四个保留的标签页，首页按可用高度切换布局的 `LayoutBuilder` 因此逐帧重建。Flutter 的 `flushLayout` 不检查祖先是否在屏，被 AI 顾问页盖住的首页照样逐帧重建和布局，跨过 compact / minimal 高度阈值时还会整棵换树。
- 聊天列表外层的 `SelectionArea` 把每段文字注册为可选对象。新消息进入视口时，要按屏幕位置重新排序全部已挂载段落，每次比较都要计算到根节点的变换。同时，手指按住消息区超过 100 ms，`SelectableRegion` 会抢走输入框焦点，输入法随即收起，又触发一轮外壳重排。
- 上下各 1.5 屏的消息缓存放大了选择排序的开销。消息滑出缓存后即被销毁，滑回来要重新解析和布局 Markdown。
- 聊天图片每次挂载都重新读文件并按原图尺寸解码。

## 改动

- `HeldKeyboardMetrics`：页面不在视野内时（路由被覆盖，或首页标签未选中），沿用最后一次在视野内时的键盘内边距和底部安全区，其余尺寸照常传递。所有页面路由通过 `WalletPageTransitionsBuilder` 自动获得这一行为，被弹窗、底部面板覆盖的页面同样适用。
- 首页外壳的 `resizeToAvoidBottomInset` 设为 `false`。账单列表用 `KeyboardInsetPadding` 自行避让键盘，搜索时只重排账单列表。
- 聊天列表去掉 `SelectionArea`，改为长按单条消息打开选择面板：面板内可跨段落选择部分文字，也可一键复制全文。跨多条消息连续选择不再支持。拖动列表时收起输入法。
- 消息缓存恢复默认范围，最近 30 行内容滑出后保留。每条消息不再单独订阅顾问记忆，时间格式化器改为共享实例。
- 聊天图片改为按图片 ID 缓存的 `ImageProvider`，缩略图按显示尺寸解码，加载期间占位固定为 240×180。输入框上方的截图预览按缩略图尺寸解码。

## 验证

在 Windows 上用 `flutter test`（debug 模式）测量。绝对值不代表手机上的耗时，请看相对比例：

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 首页四个标签已加载，打开 AI 顾问后弹出输入法，每帧耗时 | 22–60 ms | 3.6–9.5 ms |
| 输入框获焦时按住消息区 150 ms | 输入框失焦 | 保持焦点 |
| 向上滚动后再滑回，Markdown 重新挂载次数 | 1 次 | 0 次 |
| 同一列表包 `SelectionArea` 与不包，往返滚动总耗时 | 915 ms | 461 ms |

- 新增回归测试：首页标签全部加载后打开 AI 顾问，键盘动画期间被覆盖的金额和账单行重建次数为 0。去掉本次修复时该测试失败，实测重建 35 次。
- 聊天长按选择、复制全文与提示由现有聊天性能测试覆盖。聊天、导航、首屏布局、账单、图片消息和会话相关测试通过。

安装包核对：版本 `0.8.3`（versionCode 19），非调试包，签名证书与此前安装的版本一致，已通过 `adb install -r` 覆盖安装到测试手机并启动，原有数据保留。

此前手机上的版本由 Android Studio 的 `android.app` 配置安装，是 `0.5.8 / 17` 的调试包：Gradle 直接读取未刷新的 `android/local.properties`，调试模式的 Flutter 也明显慢于正式包。评估流畅度应使用正式包。
