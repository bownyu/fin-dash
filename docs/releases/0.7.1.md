# FinDash 0.7.1

本次交付源码，构建号保持 19，未生成安装包。

- 标签切换保留轻微位移，移除整屏淡入；首页整页只保留一个淡入，各分区错峰位移。玻璃导航的局部模糊不变。
- 首页首帧后延迟 1 秒预构建其他标签，每帧一个；有动画时用有间隔的计时器延后，销毁时取消。避免 `Priority.idle` 在测试调度器中的零延迟重试循环。
- 窄屏外层使用纯色，超过 960 的宽屏保留两侧渐变。聊天通过统一 SelectionArea 选择和复制，Markdown 不创建独立选择器，消息缓存约 1.5 屏。
- 保留订阅收敛后的提醒与常用分析刷新，以及语音排队状态更新。
- 增加空主库保护：已有可用恢复副本时先恢复，禁止用未初始化的主库覆盖该副本。
- 导航、首页首屏点击、主题和聊天专项串行验证 86 项通过；最终验证结果见 [整改记录](../performance-remediation-results.md)。
- 原生数据库仍为存储版本 2；不支持降级至旧版应用，恢复副本为异步同步。真机帧时间与长按、跨段落选择及复制仍待连接手机后确认。
