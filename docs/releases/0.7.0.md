# FinDash 0.7.0

本次交付源码，构建号保持 19，未生成安装包。

- **原生数据库升级至存储版本 2，不支持降级到旧版应用。OTA 回退也必须考虑数据库兼容性。** 版本 1 的主库与恢复副本一致后原地升级，无数据搬迁。
- 主库 WAL / FULL 保持每次提交立即持久化；恢复副本改为空闲 3 秒或退到后台时异步同步。同步失败不回滚已提交的数据，下一次提交或回到前台重试。
- 物理损坏时保留主库、WAL、SHM 文件，从已校验副本恢复；副本之后的修改可能丢失，显示非致命提示。恢复点与导出备份仍可使用。迁移、恢复和损坏修复在镜像完成后才报告成功。
- 新消息仅保存当前协议的回放副本，完整消息在最近 15 个用户轮次外移除冗余回放，长工具结果变为预览；错误和取消检查点保留。首次空闲时压缩存量，备份格式不变。
- 操作回执保留 30 天且最多 1,000 条；已结束任务保留 200 条；已处理操作与批次各保留 500 条。进行中任务、待确认事项继续保留；撤销入口只显示仍有完整记录的回执。
- 验证 SQLite 3.53.4（本机运行库与缓存 Android ARM64 库），支持 `VACUUM INTO`。数据库专项、压缩、备份和流式回复已验证；全量测试 346 项通过、1 项跳过。
- 真机未连接，保存耗时、帧时间和选择操作仍待实测。
