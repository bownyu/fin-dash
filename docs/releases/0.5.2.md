# FinDash 0.5.2

日期：2026 年 10 月 4 日。Android 构建号：11。从 0.5.1 可直接覆盖升级。

## 玻璃层次

扁平布局继续保留玻璃材质。本版在 0.5.1 的内容层次、米白 / 暖灰底色和克制强调色上补回玻璃表面：

- 底部导航和桌面侧栏使用裁切区域内的真实背景模糊，叠加半透明表面、细高光边缘和轻投影。内容在导航下方滚动时仍能感受到背景的变化。
- 资产主卡片使用半透明渐变高光与柔和投影。普通卡片、月度摘要和快捷入口使用透光表面，通过透明度和边界区分层次。
- 背景加入中性色的柔和明暗变化，外观选择预览同步更新。
- 真实模糊只用于浮动导航，长列表卡片不逐项增加背景模糊；不新增依赖或循环动画。
- 保留 0.5.1 的首次及后续标签切换过渡、搜索 / 筛选 / 滚动位置和系统移除动画支持。

项目约定已记录：后续扁平化调整需保留玻璃材质与表面层次。

## 数据兼容

不修改账本数据、存储结构、SQLite `user_version` 或备份 schema。

## 验证

- 静态检查无问题；Flutter 全量测试 265 项通过，1 项因缺少本地私人样本跳过。
- 既有导航测试通过，覆盖首次与重复切换、快速连续点击、状态保留、独立子页首次过渡，以及切换过程中子页背景遮住旧页面内容。
- 完成浅色 / 深色首页及滚动状态的 Flutter 渲染检查，同时检查 960 px 桌面布局与 320 px、1.3 倍字号布局；未检测到布局溢出。预览使用示例账本与本机字体，设备字体可能略有不同。
- ARM64 Flutter release 构建成功；应用 ID 为 `com.findash.fin_dash`，版本为 `0.5.2+11`，签名与 0.5.1 一致，可覆盖升级。
- Android 插件继续使用项目内 `.pub-cache`，没有新增依赖。

真机上的背景模糊性能与动画帧率仍需在目标设备体验。
