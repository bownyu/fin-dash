# 0.8.2 — 2026-10-05

本次交付桌面语音小部件的尺寸与等待动画更新源码，版本 `0.8.2+19`，未生成安装包。

新增 1×1 与 2×2 两个小部件，与原 4×2 作为三个独立条目出现在桌面小部件列表中，尺寸固定。三者共用录音、解析、直接入账和撤销流程，每个小部件实例保存各自的状态，按小部件的提供者选择布局：

- 1×1：麦克风按钮加一行文字，录音时显示计时；点卡片任意处与点按钮相同。保存后显示“已保存”，撤销或换账户需使用较大尺寸或 App。
- 2×2：状态、账单摘要、撤销／重说／重试（三者不会同时出现，共用一个位置）与按钮。点摘要换账户，转账时轮换转出与转入组合；单独换转出或转入仍在 4×2 中提供。

识别与保存时的转圈改为自带的环形渐变旋转动画。小部件按桌面的主题加载，原先使用系统默认进度条样式，在 HyperOS 上出现被方形裁切的情况；现在显式指定样式、着色、时长、插值器和透明背景，动画尺寸始终随控件缩放。

验证：Android 编译、资源链接与清单合并通过，小部件主按钮状态单元测试通过。

未在真机上验证三种尺寸的显示和转圈效果；转圈裁切的原因依据代码推断，需安装后在 HyperOS 桌面确认。
