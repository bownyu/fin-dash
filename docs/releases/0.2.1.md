# FinDash 0.2.1

- 应用设置新增检查更新，可在应用内下载并通过 Android 系统安装器升级。
- 更新包含 SHA-256、文件大小、应用 ID、构建号与签名校验，升级保留现有账本。
- Agent 支持任务级汇总、明细调整、批量确认与撤销；含 SQLite 增量账本和本地离线语音。
- 源码公开范围经过隐私检查，运行数据、私人样本、密钥、签名私钥及本地历史均不上传。

首次安装包含 OTA 的版本后，可使用“我的 → 应用设置 → 检查更新”。完整安装包包含离线语音模型，约 344 MB。

验证：213 项 Flutter 测试通过；本地 1 项私人样本测试因未提供样本跳过；22 项 Android 原生测试通过；静态检查及 release 构建通过。0.2.1 与 0.2.0 的签名证书相同。

仓库：[bownyu/fin-dash](https://github.com/bownyu/fin-dash)。OTA 固定入口：[ota-manifest.json](https://github.com/bownyu/fin-dash/releases/latest/download/ota-manifest.json)。
