# FinDash 0.5.7

日期：2026 年 10 月 4 日。Android 构建号：16。从 0.5.6 可直接覆盖升级。

## 首页层次

0.5.6 的首页各区块大多是同样描边、同样底色的卡片，主次主要靠字号区分。本版用表面层级拉开主次，并保留玻璃材质：

- **资产主卡**：保留半透明渐变、高光描边和轻投影，是首页唯一带投影的卡片。“净资产 / 总资产 / 总负债”选择器作为卡头；原先卡头的标签与“↕”切换和选择器重复，已去掉。金额隐藏按钮移到金额右侧。资产卡因此少一行，首屏能露出更多内容。
- **月度摘要**：本月收入与支出合并到一块面板，中间用细线分隔。宽屏时仍在资产卡右侧上下排列。
- **操作区**：“记一笔 / 转账”改为无边框的浅色块按钮，文字为正文色；“AI 顾问 / 语音记账”保留描边表面和强调色图标。两行按钮的位置与间距不变，核心入口仍在首屏完整可点。
- **账单行**：金额列原先与标题平分剩余宽度，导致金额停在行中间、长标题被截到一半宽度。现在金额列按内容宽度靠右（最宽 140 逻辑像素，超长时缩小），并使用等宽数字，标题占用其余宽度。账单页、账户流水等所有账单列表同步生效。

## 首次动画

0.5.1 让主标签的首次切换也有动画，但动画时钟在切换当帧就开始计时。首次进入的页面要在这一帧完成构建，如果构建耗时接近动画时长，下一帧画面已接近终点，看起来仍像直接换页。

- 新增 `SettledStart`：动画进度在首帧（构建帧）保持为 0，从下一帧开始计时。
- 主标签切换、首页首次淡入，以及所有子页面推入（`openPage`、聊天会话切换、支付记录核对）都使用该方式。返回动画不受影响。
- 只多等一帧（约 16 ms）；系统开启“移除动画”时仍直接跳到结果。

底部导航的选中状态改为一块在各标签间滑动的高亮，越过中间的“记一笔”按钮；图标和文字颜色同步过渡。

## 数据兼容

不修改账本数据、存储结构、SQLite `user_version` 或备份 schema。

## 验证

- 静态检查无问题。
- `navigation_test`、`home_first_screen_test`、`theme_test` 共 79 项通过。原有的切换与推入动画测试改为模拟耗时较长的首帧，检查动画仍从起点开始，而不是在首帧之后跳到中途。
- 首屏回归覆盖 320×568 至 600×960、1 / 1.3 / 1.6 / 2 倍字号和浅色 / 深色，核心入口完整可见、可点击。
- 在 390×844 示例账本的网页版上人工检查首页层次、账单金额对齐、标签切换与导航高亮滑动。
