# FinDash 0.5.7

日期：2026 年 10 月 4 日。Android 构建号：16。从 0.5.6 可直接覆盖升级。

## 导航选中颜色

底部导航此前为每个项目分别执行 220 毫秒背景渐变，切换时旧项褪色和新项着色同时发生，短暂显示两个选中背景。本版让背景、图标与文字在切换首帧同步更新，只有当前项目显示选中颜色。点击不再留下染色水波；鼠标悬停与键盘焦点保留轻微中性色反馈。

保留玻璃导航、页面的淡入与轻微上移动画、已访问页面的搜索 / 筛选 / 滚动状态，以及系统移除动画支持。

## 数据兼容

不修改账本数据、存储结构、SQLite `user_version` 或备份 schema。
