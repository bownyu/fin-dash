# FinDash 0.3.0

日期：2026 年 10 月 3 日。Android 构建号：6。

本次交付优先处理功能错误，再优化常用交互。覆盖审查报告中的 16 个操作逻辑项，并统一全部 15 处默认下拉控件的呈现。

## 主要改动

- 未保存内容离开前确认；保存中阻止返回和重复操作，保存失败保留输入。
- 转入和转出互相排除，信用卡还款默认选择另一付款账户；支持 1–31 日，短月按当月末日处理。
- 退款需要选择原支出及确认实际到账，原消费保留，退款独立归入退款收入；累计退款校验、事务回滚及事件幂等保持生效。
- 支付批量入账不再默认全选，确认摘要明确同一账户；误忽略可恢复，清除原文后不可恢复。
- 账本恢复前保留独立快照，可从备份页恢复。完整 JSON 备份可包含聊天图片，图片总量上限 64 MB，导入前验证引用和 SHA-256。
- 统一账户、分类、状态、协议和日期选择面板，账户带图标及余额，分类支持图标网格和搜索。
- 语音入口进入首页操作区，小屏和大字体使用两列；小屏记账默认折叠金额键盘，支持手动展开。
- 月和年使用对应选择器，环图过渡及分类点击、趋势点击查看金额、汇总金额过渡尊重减少动态效果。
- 账单返回先退出多选；从聊天切换历史会话返回原聊天页；未发送草稿离开和新建前确认；AI 测试连接与保存状态分开，高级选项折叠。
- 金额隐藏覆盖账户、账单、预算、目标、导入和通知等数值摘要；编辑输入、备注与 AI 原文保留，设置中说明范围。
- 语音录音切后台明确告知本次录音中断；Android 小部件可分别切换转入／转出，排除相同账户。
