# 0.8.1 — 2026-10-05

本次交付桌面语音小部件的流程与界面更新源码，版本 `0.8.1+19`，未生成安装包。

小部件的语音解析出完整账单（金额、账户、分类齐全，且为单笔或两笔非转账）时直接入账。保存后小部件保留草稿和已保存账单：点“撤销”删除账单，点账单轮换账户，转账可分别换转出、转入账户。更换账户在一次事务内改写原账单，只在账单自保存后未被修改时执行，否则提示到账单页面处理。信息不全时仍显示草稿，可语音补充或换账户后确认。小部件无法核对的多笔草稿由主按钮直接打开 App；没有草稿时点卡片也会打开 App，便于处理未配置 AI、未添加账户或账本已锁定等情况。

录音进入“正在录音”后，后台异步启动 Flutter 运行时并初始化账本，与说话时间重叠；加载器在后台线程完成，主线程不等待。录音期间整张卡片都可点击结束，计时由 Chronometer 在桌面端走秒，录音过程不增加小部件刷新次数。小部件颜色通过资源区分浅色与深色模式。

账本存储 schema、备份 schema 和手动结束录音的规则未变。

验证：小部件运行时直接入账、重复确认幂等、已保存账单换账户、撤销，两笔账单入账与撤销，多笔草稿要求打开 App，语音补充沿用原草稿且不残留草稿，转账两侧账户切换等 Dart 测试通过；Android 编译、资源链接和小部件主按钮状态单元测试通过。

未做 Android 真机或模拟器上的小部件显示、冷启动延迟和录音交互测量。
