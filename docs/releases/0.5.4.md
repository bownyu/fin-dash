# FinDash 0.5.4

日期：2026 年 10 月 4 日。Android 构建号：13。从 0.5.3 可直接覆盖升级。

## 首页操作区

0.5.3 使用剩余屏幕高度将 AI / 语音入口推到页面下方，造成摘要与按钮之间的大块空白，手动记账 / 转账也被排到更下方。本版移除这一撑高布局，将首屏可达与整体协调一起处理。

- 操作区紧接摘要，保持 16 逻辑像素的区块间距。
- 上行为“记一笔 / 转账”，下行为“AI 顾问 / 语音记账”，行间距为 12 逻辑像素。次要操作采用较轻的图标和文字，四个入口形成连续的操作区。
- 小屏或较大字号收紧上方资产摘要，必要时将月度详情与资产选项放到操作区之后。极紧凑布局保留资产金额、资产类型切换与金额显隐。
- 核心入口仍完整显示在首屏，不固定悬停；所有操作继续随内容滚动。保留玻璃材质、克制配色、首次切换动画与页面状态。
- 回归验证同时检查首屏可见、实际点击和区块间距，禁止用大块留白满足单项可见性要求。

## 数据兼容

不修改账本数据、存储结构、SQLite `user_version` 或备份 schema。

## 验证

- 静态检查无问题；Flutter 全量测试 321 项通过，1 项因缺少本地私人样本跳过。
- 既有 56 项首屏回归加入间距约束：摘要到操作区为 12～20 逻辑像素，两行操作之间为 8～16 逻辑像素，防止用撑高空白把按钮推到底部；继续检查完整露出、中心与四角可点、实际打开 AI / 语音入口和随内容滚动。
- 覆盖 320×568 至 600×960 的六种竖屏尺寸、1 / 1.3 / 1.6 / 2 倍字号、浅色 / 深色，以及较大的系统安全区、待确认支付和空账本。
- 实际 Flutter 渲染检查包含反馈画面相近的 412×892 / 1.3 倍字号，以及 320×568 / 2 倍字号；首页与滚动后均无布局溢出，已人工检查操作区与摘要协调排列。预览使用示例账本与本机字体，设备字体可能略有不同。
- Android 插件继续使用项目内 `.pub-cache`，没有新增依赖。

- ARM64 Flutter release 构建成功，应用 ID 为 `com.findash.fin_dash`，版本为 `0.5.4+13`；APK 签名验证通过，签名证书与 0.5.3 一致，可覆盖升级。
